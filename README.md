# Portfolio Website

A personal portfolio website showcasing projects, skills, and achievements. Built with **HTML, CSS, and JavaScript**.

---

## 📂 Project Structure
- `index.html` → Main entry point of the website
- `styles.css` → Custom styles and layout
- `script.js` → Interactive features and DOM manipulation
- `README.md` → Documentation for the project
- `.gitignore` → Git ignored files
- `AGENTS.md` / `CLAUDE.md` → Notes or documentation (optional)
- `next-env.d.ts` → TypeScript environment definitions

---

## 🚀 Features
- Responsive design for desktop and mobile
- Interactive navigation and smooth scrolling
- Project showcase section
- Contact form integration
- Clean and minimal UI

---

## 🛠️ Technologies Used
- **HTML5** for structure
- **CSS3** for styling
- **JavaScript (ES6)** for interactivity
- **Git/GitHub** for version control
